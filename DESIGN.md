## Brand & Style

### Brand Personality & Core Narrative
The brand personality embodies quiet intelligence, operational precision, and seamless intellectual partnership. The design language avoids hyper-futuristic neon tropes, sterile corporate blue facades, and literal motorsport motifs. Instead, it frames the environment as an intentional workshop—a serene, high-order digital think-tank where humans and autonomous AI specialists converge on complex problems.

The interface evokes an editorial, book-like calm: warm, tactually grounded, and devoid of cognitive friction. It feels authoritative yet inviting, engineered for marathon cognitive tasks, deep synthesis, and high-density multi-agent orchestration.

### Target Audience
- Strategic leaders, researchers, product architects, and engineering leads who orchestrate multi-agent workflows.
- Practitioners requiring high contextual clarity, transparent agent attribution, and fatigue-free environments during extended sessions.

### Design Aesthetic
- **Minimalist Editorial Modernism**: Ample structural breathing room, sharp typometric balance, warm parchment-like neutrals, and subtle, functional warmth.
- **Tone & Voice (Indonesian Language UI)**: Concise, professional, and clear (*"Kolaborasi Berjalan"*, *"Arsip Memori"*, *"Kirim Instruksi"*).

## Colors

The palette establishes an organic paper-and-charcoal baseline, punctuated by a precise signal amber that denotes vitality, streaming tokens, and direct human-agent interactions.

### Palette Architecture
- **Primary Accent (`#EA580C`)**: Warm Burnt Amber. Used deliberately for primary interactive triggers, active inference streams, real-time sync beacons, and key system highlights.
- **Secondary / Deep Slate (`#22252B` / `#121316`)**: Grounded charcoal tones used for secondary action surfaces, code blocks, dark telemetry badges, and structural contrast.
- **Tertiary Accent (`#D97706`)**: Soft ochre gold used for memory persistence, token metrics, and ambient agent states.
- **Canvas & Neutral Surfaces**:
  - `surface-canvas` (`#FBFBFA`): Warm ivory canvas providing long-form reading comfort.
  - `surface-subtle` (`#F4F4F0`): Structural backgrounds, message wrappers, and panel dividers.
  - `surface-elevated` (`#FFFFFF`): Elevated cards, active agent dialogue bubbles, and modal layers.
  - `border-subtle` (`#EAEAE4`): Ghost borders maintaining boundary clarity without contrast clutter.
- **Typography & Ink**:
  - `text-primary` (`#1E2024`): High-contrast warm charcoal for uncompromising legibility.
  - `text-secondary` (`#6B7280`): Mid-tone slate for supporting metadata and secondary labels.
  - `text-muted` (`#9CA3AF`): Soft grey for structural labels, timestamps, and model identifiers.

## Typography

The type system blends contemporary humanist geometric sans-serif with a razor-sharp monospace companion.

### Type Pairings
- **Primary Text (`Plus Jakarta Sans`)**: Delivers open apertures, rhythmic letterforms, and superior optical comfort across all headlines and running chat dialogue.
- **Telemetry & Technical Layer (`JetBrains Mono`)**: Dictates agent IDs, latency readouts, memory addresses, token counters, and code blocks.

### Typography Hierarchy Rules
- Message body text relies strictly on `body-md` (15px) with an expanded line height (24px) to preserve reading flow across multi-paragraph AI synthesis.
- Monospace tokens (`label-xs` and `label-sm`) must always render in tabular numerals (`font-variant-numeric: tabular-nums`) to avoid layout jitter during live token streaming.
- Indonesian interface labels favor clear sentence casing (*"Riwayat sesi"*, *"Status agen"*, *"Simpan ke memori"*).

## Layout & Spacing

### 3-Pane Collaboration Studio Architecture
The desktop studio operates on an asymmetrical 3-pane structure optimized for widescreen workflows:

1. **Left Navigation Panel (Ruang Kerja / Navigasi)**
   - Fixed width: `260px` (Collapsible to icon rail: `68px`).
   - Hosts workspaces, channel threads, agent orchestrations, and system settings.
2. **Central Collaboration Stream (Alur Percakapan & Komposer Multimodal)**
   - Fluid width: Flexible column with max-width containment at `840px` for optimal typographic reading length.
   - Anchors the live conversation thread and the sticky multimodal composer at the bottom edge.
3. **Right Roster & Telemetry Panel (Daftar Agen & Kesehatan Sistem)**
   - Fixed width: `320px` (Collapsible to zero).
   - Houses active agent status, runtime latency, active tool invocations, and Soul Memory context drawers.

### Responsive Breakpoints & Reflow
- **Desktop (≥ 1280px)**: Complete 3-pane orchestration with simultaneous visibility.
- **Tablet (768px – 1279px)**: Left pane collapses to icon rail (68px); Right panel converts into an off-canvas drawer toggled via header action. Central stream retains priority.
- **Mobile (< 768px)**: Single-pane stack. Left nav and Right telemetry become bottom sheets. Composer docks above the system soft keyboard.

## Elevation & Depth

Visual hierarchy is communicated through calm tonal layering and soft hairline borders rather than high-contrast dropshadows.

### Elevation Levels
- **Level 0 (Kanvas Dasar - `#FBFBFA`)**: The foundational canvas of the studio.
- **Level 1 (Panel Struktural - `#F4F4F0`)**: Sidebar, top bar, and right panel. Framed with subtle hairline dividers (`1px solid #EAEAE4`).
- **Level 2 (Kartu Percakapan & Modul - `#FFFFFF`)**: Dialogue containers and agent contribution cards. Uses an ambient low-opacity shadow:
  `box-shadow: 0 1px 3px rgba(30, 32, 36, 0.04), 0 1px 2px rgba(30, 32, 36, 0.02)`.
- **Level 3 (Drawer & Komposer Melayang - `#FFFFFF`)**: The sticky composer bar and Soul Memory inspection sheets:
  `box-shadow: 0 10px 25px -5px rgba(30, 32, 36, 0.06), 0 8px 10px -6px rgba(30, 32, 36, 0.04)`.
- **Level 4 (Modal Dialog - `#FFFFFF`)**: Context switches and agent configuration modals, accompanied by a tinted backdrop overlay (`rgba(18, 19, 22, 0.35)` with `backdrop-filter: blur(4px)`).

## Shapes

The system uses balanced structural radii (`roundedness: 2` = 0.5rem base) to maintain an architectural, editorial demeanor without feeling sharp or overly toy-like.

- **Base Radius (`0.5rem` / `8px`)**: Interactive inputs, contextual menus, tool chips, and code inline blocks.
- **Large Radius (`1rem` / `16px`)**: Agent message bubbles, composer dock, and panel containers.
- **Full Radius (`9999px`)**: User presence indicators, real-time agent status pills, and small icon buttons.

## Components

### 1. Tombol (Buttons)
- **Utama (Primary)**: Background `#EA580C`, text `#FFFFFF`, font weight `500`. Hover state darkens to `#D97706`. Zero harsh shadow; subtle scale transition.
- **Sekunder (Secondary)**: Background `#F4F4F0`, border `1px solid #EAEAE4`, text `#1E2024`. Hover state shifts background to `#EAEAE4`.
- **Ghost / Minimal**: Transparent background, text `#6B7280`. Hover state triggers background `#F4F4F0` and text `#1E2024`.

### 2. Gelembung Percakapan (Message Stream Bubbles)
- **Pesan Pengguna (Human Message)**: Soft warm tint `#F4F4F0`, border `1px solid #EAEAE4`, aligned right or flush editorial.
- **Respons Agen AI (Agent Message)**: Crisp white background (`#FFFFFF`), border `1px solid #EAEAE4`. Header displays the agent's identity pill, avatar indicator, model version (JetBrains Mono), and latency badge.
- **Pita Pemikiran Agen (Agent Thought Stream)**: Collapsible accordion tinted in `#FBFBFA` with a subtle left border in `#EA580C`.

### 3. Chip & Status Badge
- **Status Agen Aktif**: Full-pill badge (`rounded-full`), background `rgba(234, 88, 12, 0.08)`, text `#EA580C`, paired with a pulsing 6px amber dot.
- **Indikator Model & Token**: Monospace text (`label-xs`), background `#F4F4F0`, text `#6B7280`, padding `2px 8px`.

### 4. Komposer Multimodal (Multimodal Composer)
- Elevated sticky pill/dock container (`rounded-xl`), background `#FFFFFF`, border `1px solid #EAEAE4`.
- Integrated attachment pills (Dokumen, Gambar, Konteks Memori).
- Trailing send trigger using the primary Burnt Amber accent.

### 5. Laci Soul Memory (Soul Memory Drawer)
- Sliding panel displaying vector-retrieved episodic memories.
- Uses subtle parchment cards (`#FFFFFF`) with small golden tag markers (`#D97706`) denoting memory retention strength and timestamp.

### 6. Bidang Input (Inputs & Forms)
- Default background `#FFFFFF`, border `1px solid #EAEAE4`, text `#1E2024`.
- Focus state: border color `#EA580C`, with a soft glow ring `box-shadow: 0 0 0 3px rgba(234, 88, 12, 0.12)`.
