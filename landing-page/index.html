A few things
to know.

Who is Pitstop Chat for?

Builders and project leads who already work with AI agents and want one place to brief them, discuss options, and record decisions.

Can I choose which agents respond?

Yes. Choose who participates in a session and direct a message to a specific agent when you want their perspective.

What’s the difference between Project Memory and Soul Memory?

Project Memory holds decisions and context for a specific project. Soul Memory holds your general communication preferences across projects.

Does the walkthrough connect to real agents?

No. It’s an example you can explore right here. The Pitstop workspace runs locally and uses the AI tools you connect to it.
