# Pitstop

Pitstop is a local multi-agent collaboration workspace using Next.js App Router, React, TypeScript, Tailwind CSS, and a Node.js backend.

The user discusses projects with connected AI agents through shared project sessions. Current functionality includes project/session management, participant selection, project managers and General Manager decisions, mention routing, real-time replies, file/image attachments, profile settings, model/effort settings, quotas, chat search, and collapsible navigation/team panels.

Project Memory stores project concepts, approved decisions, and progress per project. Soul Memory stores global communication preferences. Preserve their separation, existing data, and provider/account behavior.
